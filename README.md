# 23 机电一体化“七星班” · 班级建设展示平台

班主任能力比赛参赛配套的班级建设展示网站。纯静态、零依赖、零构建，直接用浏览器打开即可。

## 站点地图

| 页面 | 内容 |
|---|---|
| `index.html` | 首页 · 育人图景概览 |
| `plan.html` | 班级建设方案 |
| `groups.html` | 七星组榜 |
| `growth.html` | 成长进步 |
| `honor.html` | 荣誉空间 |
| `activities.html` | 活动风采（含「弘扬非遗 · 学习前辈」视频学习区） |
| `teacher.html` | 教师管理 |
| `student.html` | 学生自查 |

## 目录结构

```
.
├── *.html                 页面
└── assets/
    ├── css/               样式（base / components / pages）
    ├── js/                数据与交互（data / charts / ui）
    ├── img/               班徽、醒狮社照片、证书等图片
    └── media/             非遗学习视频与封面
```

## 技术说明

- 纯静态站点，无后端、无构建步骤。
- 数据集中在 `assets/js/data.js` 的 `window.QX` 对象里，页面按需渲染。
- 教师管理页的填报数据存于浏览器 `localStorage`，仅本机可见。
- 全部资源使用相对路径，可部署在任意子目录。
